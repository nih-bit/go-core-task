# Задания по модулю Go-core

Решения заданий модуля Go-core.

## Структура

```
go-core-task/
├── 1/
│   ├── main_1.go
│   └── main1_test.go
├── 2/
│   ├── main_2.go
│   └── main2_test.go
├── 3/
│   ├── main_3.go
│   └── main3_test.go
└── README.md
```

## Запуск

```bash
go run ./1      # запустить задание 1
go run ./2      # запустить задание 2
go run ./3      # запустить задание 3
```

`1/main1_test.go` - тесты
